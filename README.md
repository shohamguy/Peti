# Peti 🐾

היומן המונפש של הכלב שלכם. אפליקציה לטלפון (PWA) שמתקינים למסך הבית, בעברית ומימין לשמאל.

## מה יש בפנים
- **בית**: סצנה חיה עם הכלב המצויר. הוא מכשכש, ממצמץ, קופץ כשמלטפים אותו, ומצב הרוח שלו משתנה לפי מה שעשיתם היום (רעב, משועמם, שמח, ישן בלילה). משימות יומיות, רצף ימים, רישום מהיר ותזכורות.
- **יומן**: רישום בלחיצה אחת של ארוחות, טיולים, פיפי וקקי, משחק, אימון ועוד, עם ביטול מיידי ועריכה (דקות, הערה, שעה).
- **גדילה**: גיל מדויק, שלבי התפתחות לפי גודל הכלב, גרף משקל אינטראקטיבי, טבלת שקילות ואלבום תמונות לפי גיל.
- **בריאות**: תזכורות לחיסונים, פרעושים וקרציות, תילוע, רישיון ועוד. ״בוצע״ מחשב לבד את המועד הבא. וגם פרטי וטרינר, שבב ורישיון.
- **טריקים**: 12 טריקים עם הסבר איך מלמדים, רמות התקדמות וטריקים משלכם.
- **נקודות, רמות והישגים**, קונפטי, כמה כלבים במקביל, מצב כהה, ועבודה בלי אינטרנט.

## הרצה
```bash
npm install
npm run dev        # פיתוח: http://localhost:5173
npm run build      # בילד של האפליקציה ל-dist/ (כולל service worker ו-manifest)
npm run preview    # הרצת הבילד מקומית
```

## התקנה בטלפון
האפליקציה צריכה לרוץ מכתובת HTTPS. הדרך הפשוטה: GitHub Pages.
1. ממזגים את הקוד ל-`main`.
2. ב-GitHub: **Settings → Pages → Source: GitHub Actions** (פעם אחת).
3. ה-workflow שב-`.github/workflows/pages.yml` מפרסם אוטומטית, והאפליקציה תהיה ב-`https://shohamguy.github.io/Peti/`.
4. בטלפון פותחים את הכתובת:
   - **אנדרואיד (Chrome)**: ״התקנת אפליקציה״ (יופיע גם באנר בתוך Peti).
   - **אייפון (Safari)**: כפתור השיתוף ואז ״הוספה למסך הבית״.

אפשר גם כל אחסון סטטי אחר (Netlify, Vercel, Cloudflare Pages): מעלים את תיקיית `dist`.

## איפה נשמרים הנתונים
- באפליקציה המותקנת: במכשיר עצמו (IndexedDB). בהגדרות יש שמירת גיבוי ושחזור.
- בגרסת התצוגה ב-claude.ai (`npm run build:artifact`): בחשבון Claude של המשתמש, וכך יש סנכרון בין מכשירים.

## מבנה
- `src/screens/`: המסכים (בית, יומן, גדילה, בריאות, טריקים, הרשמה, הגדרות, הישגים)
- `src/components/Mascot.tsx`: הכלב המצויר והאנימציות שלו
- `src/components/WeightChart.tsx`: גרף המשקל
- `src/lib/store.ts`: מצב האפליקציה והפעולות; `src/lib/gamify.ts`: נקודות, רמות, הישגים ומצב רוח
- `src/lib/persist.ts`: שמירה (IndexedDB או ענן)
- `vite.config.ts`: הבילד, כולל יצירת ה-service worker
- `scripts/make-icons.mjs`: יצירת אייקוני האפליקציה מ-`public/icons/icon.svg`

## צעדים הבאים

- שיתוף הכלב עם בני משפחה (כמה משתמשים)
- עטיפה לחנויות (TWA ל-Google Play, Capacitor ל-App Store)
