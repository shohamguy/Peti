# Peti

אפליקציית משרות לנייד (בסגנון JobMaster) — ניתנת להתקנה על המסך הראשי (PWA) באנדרואיד ובאייפון.

## מה יש באפליקציה
- **משרות** — חיפוש חופשי, סינון לפי אזור, היקף ותחום (צ'יפים)
- **עמוד משרה** — פרטים, שיתוף, שמירה והגשת מועמדות בלחיצה (bottom sheet)
- **שמורות** — משרות ששמרתם ומשרות שהגשתם אליהן
- **פרסום משרה** — המשרה מופיעה מיד ברשימה
- **פרופיל** — פרטים להגשה מהירה, סטטיסטיקה וכפתור התקנה
- עובד גם בלי אינטרנט (service worker), ניווט תחתון כמו באפליקציה

> כרגע כל הנתונים של המשתמש (שמירות, הגשות, פרופיל, משרות שפורסמו) נשמרים במכשיר עצמו (localStorage).

## הרצה מקומית
```bash
npm install
npm run dev          # פיתוח
npm run build && npm start   # גרסת production (כולל service worker)
```

## התקנה בנייד
ההתקנה עובדת רק כשהאתר מוגש ב-HTTPS. הדרך הקלה: לחבר את הריפו ל-[Vercel](https://vercel.com) (חינם) ולפתוח את הכתובת בנייד.
- **אנדרואיד (Chrome):** יופיע באנר "התקנה", או תפריט ⋮ ← "התקנת אפליקציה"
- **אייפון (Safari):** כפתור שיתוף ⬆️ ← "הוספה למסך הבית"

## מבנה
- `src/app/page.tsx` — מסך משרות + חיפוש
- `src/app/jobs/[id]/page.tsx` — עמוד משרה + הגשת מועמדות
- `src/app/saved`, `src/app/post`, `src/app/profile` — שאר הטאבים
- `src/app/manifest.ts` — manifest של ה-PWA
- `public/sw.js` — service worker (אופליין)
- `src/lib/jobs.ts` — נתוני דמה, `src/lib/store.ts` — מצב מקומי במכשיר
- `scripts/make-icons.js` — יצירת אייקוני האפליקציה

## צעדים הבאים
- שרת ובסיס נתונים (למשל Supabase) כדי שמשרות והגשות יגיעו למעסיקים
- התחברות למחפשי עבודה ולמעסיקים, העלאת קורות חיים
- התראות push על משרות חדשות
- עטיפה לחנויות (TWA ל-Google Play / Capacitor ל-App Store)
